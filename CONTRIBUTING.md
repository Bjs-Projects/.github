# Contributing

1. Create or select an issue.
2. Work on a descriptive branch, not directly on `main`.
3. Run the repository's local validation contract.
4. Open a pull request and complete the inherited template.
5. Link the issue with `Closes`, `Fixes`, or `Resolves` where appropriate.
6. Review the complete GitHub diff and resolve every discussion.
7. Use squash merge and delete the source branch.

Project-specific rules in `AGENTS.md`, `PROJECT.md`, or repository documentation take precedence over this generic guidance.
